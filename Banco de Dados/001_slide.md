## RESUMO 

Este documento aborda conceitos fundamentais, tipos, modelos, arquiteturas, vantagens e funções de bancos de dados e SGBDs.

﻿Conceitos Gerais de Banco de DadosUm banco de dados é uma coleção de dados relacionados que representam aspectos do mundo real.

﻿Pode ser visto como um armário eletrônico de arquivos com dados persistentes.

﻿Os dados permanecem até serem explicitamente removidos.

﻿Um banco de dados é projetado para um propósito específico e possui significado inerente.

﻿Tipos de Dados e Banco de DadosDados estruturados, semi-estruturados e não estruturados diferem na organização e processamento.

﻿Banco de dados operacionais gerenciam operações diárias, suportando aplicações OLTP.

﻿Banco de dados analíticos suportam análise de grandes volumes de dados, usando modelos desnormalizados e esquemas dimensionais.

﻿Modelos de Banco de DadosModelos hierárquico e rede são antigos, usados em sistemas legados.

﻿Modelo relacional usa tabelas inter-relacionadas com SQL, garantindo alta integridade.

﻿Modelo objeto-relacional combina conceitos de orientação a objetos com bancos relacionais.

﻿Modelos NoSQL incluem documental, chave-valor, colunar e grafos, ideais para escalabilidade e Big Data.

﻿Sistemas Gerenciadores de Banco de Dados (SGBD)SGBD é um software que permite criar, manipular, proteger e compartilhar bancos de dados.

﻿Classificações incluem modelos de dados, número de usuários, arquitetura, aplicação e custo.

﻿Vantagens incluem controle de redundância, segurança, integridade, recuperação, acesso eficiente e suporte a transações.

﻿Funções e Profissionais de Banco de DadosSGBDs suportam operações de definição, manipulação, recuperação e segurança de dados.

﻿Administradores de banco (DBA) cuidam da operação técnica e manutenção.

﻿Administradores de dados (DA) gerenciam políticas, qualidade e governança dos dados.

﻿Projetistas de banco criam modelos conceituais, lógicos e físicos, garantindo desempenho e integridade.

﻿Níveis de Abstração do Modelo de DadosOs modelos vão do conceitual ao físico, representando dados de forma independente e dependente de tecnologia.

﻿Modelo conceitual usa diagramas ER para descrever entidades e relacionamentos.

﻿Modelo lógico representa a estrutura vista pelo usuário, usando modelos como relacional.

﻿Modelo físico detalha armazenamento, desempenho e comandos SQL para implementação.
